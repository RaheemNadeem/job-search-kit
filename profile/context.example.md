# Extra context (optional)

Copy to `profile/context.md` and write anything true about you that doesn't fit
the structured profile: side projects, domain knowledge, languages you speak,
certifications in progress, the kind of team you work best in.

The AI reads this as extra ground truth when scoring jobs and tailoring
resumes. It never invents facts, so the more real detail you give it here, the
better it can match you to a job.

`profile/context.md` is git-ignored.
